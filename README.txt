AMIT PROMOTERS HOMEPAGE
=======================

Files:
- index.html                 Page structure and Bootstrap navigation
- style.css                  Colors, spacing, Flexbox layout, responsive styles
- assets/                    Logo and page photos

How to open:
1. Keep index.html, style.css, and the assets folder together.
2. Double-click index.html to open the page in your browser.
3. Use an internet connection for Bootstrap, Bootstrap Icons, and Google Fonts.

How to edit:
- Text, links, prices, and property information: index.html
- Colors, sizes, spacing, and mobile breakpoints: style.css
- Photos: replace files in assets/ with photos using the same filenames.

Notes:
- Featured properties and prices are sample content from the design concept.
  Replace them with confirmed listings before publishing.
- Page photos are generated design visuals, not photos of actual listings.
- The contact number is taken from a public Amit Promoters listing. Confirm it
  with the business before launching the site.
- Navigation, cards, and sections use Flexbox. No CSS Grid is used.
- Bootstrap's JavaScript bundle is used only for the mobile menu.
